What the redesign has to fix

Read as a whole, today's app is a well-built admin console: one border weight, one radius, one grey, no hierarchy between the emotional moment (a successful connection) and a form field. Nothing here is wrong — it just doesn't feel like the product the brief describes. The redesign keeps every rule this code enforces (no directory, no guest list, stored-state-not-tapped-state, two-step destructive confirms) and changes only the surface, the shape language, and the motion.
